# EGLearn Custom GPT configuration

This directory will contain the versioned instructions and knowledge files used to create the EGLearn speaking coach in ChatGPT's GPT builder.

The Custom GPT is the ChatGPT Plus voice surface. It does not use an OpenAI API key. Voice mode cannot invoke Actions, Apps, MCP servers, or plugins, so saving happens only after the learner exits voice and returns to text in the same conversation.

Module 1 will add the production instruction set, review contract, examples, and validation fixtures.
